## Proje Hakkında
ASP.NET Core MVC (.NET 10 LTS) ve SQL Server kullanılarak geliştirilen; veteriner kliniklerinin sunduğu hizmetleri, veteriner hekimlerin uzmanlık alanlarını ve müsaitlik takvimlerini, evcil hayvanların muayene/aşı geçmişlerini ve çakışma kontrollü randevu süreçlerini yöneten web uygulamasıdır. Sistem ayrıca LINQ tabanlı raporlama sunan REST API uçları ve yetkilendirme korumalı MCP (Model Context Protocol) sunucusu içermektedir.
